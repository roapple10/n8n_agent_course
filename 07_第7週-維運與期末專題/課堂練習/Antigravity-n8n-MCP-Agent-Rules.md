# Antigravity n8n MCP Agent 規則範本

將這份規則複製到你的專題資料夾，命名為 `AGENTS.md`，再用 Antigravity IDE 開啟該資料夾。這些規則讓 Agent 在操作 n8n 前先查資料、提出計畫並驗證結果。

```md
# n8n 工作流程開發規則

- n8n MCP 只連接本機測試環境，網址為 `http://localhost:5678`。
- 開始開發前，先閱讀課程 `n8n AI Automation Workshop/n8n-skills/SKILL.md`，再查詢相關節點說明與範本。
- 先以簡短步驟回報流程架構、輸入、輸出、外部副作用和測試方式；未獲使用者確認前，不建立或修改工作流程。
- 新流程以未啟用狀態建立，優先使用 Manual Trigger 和假資料，不設定 Credentials，不呼叫外部 API。
- 建立前先搜尋範本與節點；建立後先執行節點及工作流程驗證，修正錯誤後再回報 workflow ID 和驗證結果。
- 不要啟用、發布或執行會寄信、發訊息、寫入正式資料、刪除資料或產生費用的工作流程。
- 不要修改或刪除既有工作流程、Credentials、資料表或 MCP 權限，除非使用者逐項確認。
- 不要要求使用者把 API Key、Token、密碼、個資或正式資料貼進聊天；不要將這些資料寫進檔案或版本控制。
- 若需求不完整、操作會產生外部副作用，或目標工作流程不是本次建立的測試流程，先停下來詢問。
```
