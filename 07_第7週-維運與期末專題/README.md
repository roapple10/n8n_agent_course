# 第 7 週：維運與期末專題

本週包含錯誤處理、部署檢查、期末專題規劃，以及用 Antigravity IDE Agent 透過 MCP 開發和驗證本機 n8n 工作流程。

## 學習順序

1. 閱讀[ n8n MCP 與 Antigravity Agent 實作教學](00-n8n-MCP與Antigravity-Agent實作.md)。
2. 依教學使用 [Antigravity MCP 設定範例](課堂練習/Antigravity-n8n-mcp-config.example.json)連接測試用的本機 n8n。
3. 將[Agent 規則範本](課堂練習/Antigravity-n8n-MCP-Agent-Rules.md)複製到練習專題目錄並命名為 `AGENTS.md`。
4. 使用 [上午錯誤處理與部署檢查](課堂練習/上午-錯誤處理與部署檢查.json)和[下午期末專題骨架](課堂練習/下午-期末專題起始骨架.json)完成既有練習。

## 參考內容

- [n8n AI Automation Workshop](../n8n%20AI%20Automation%20Workshop/README.md)：工作流程範本、節點參考與既有 `n8n-mcp` 設定模式。
- [官方範本延伸練習](官方範本延伸練習.md)
