# 2026 更新：以可驗收的實作學習

n8n 的學習不再只看節點清單。第一堂課用「輸入、處理、輸出、失敗時怎麼辦」描述任何需求，並在畫布上建立最小流程。官方文件目前將 data mapping、表達式、執行資料與 workflow sharing 視為日常工作流能力；先看每個節點的 Input/Output，再改設定。

## 課堂練習

匯入 `課堂練習/上午-n8n啟航與資料流.json`。修改 `student_name` 與 `score`，執行後觀察表達式產生的 `passed`（分數大於等於 60）及 `lesson_summary`，並說明每個節點產生了什麼 item。加分挑戰：自行新增日期欄位。完成後再將手動觸發改成你選擇的 trigger，但不要啟用工作流。

## Docker 部署與維運基礎

本機 Docker 適合學習與原型；上線前要另外處理固定的 encryption key、資料庫備份、時區、反向代理與 HTTPS、execution data 保留政策，以及升版前的備份與還原演練。工作量變大時，官方架構提供 queue mode、worker 與 task runners 等選項；先量測 execution 與瓶頸，再決定是否採用。
