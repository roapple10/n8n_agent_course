##  第一階段：認知與準備（第1週）

###  目標
- 理解「低程式碼」和「自動化」的核心思想
- 成功部署一個可運行的 n8n 實例 (使用 Docker Compose)
- 熟悉 n8n 的介面和基本操作

###  學習內容
1. **閱讀核心理念**
   - [1] 閱讀：這份教程前兩章
   - [2] 理解：n8n 不是工業級系統，而是「手工藝製品」——**能用就行，不必完美**
   - [3] 明確：n8n 的核心價值是「給 AI 裝上手腳」

2. **部署 n8n (推薦使用 Docker Compose)**
   - 相比單純的 `docker run`，`docker-compose` 更容易管理配置和數據持久化。
   - 創建一個 `docker-compose.yml` 文件：
   ```yaml
   version: '3.8'
   services:
     n8n:
       image: docker.n8n.io/n8nio/n8n
       restart: always
       ports:
         - "5678:5678"
       environment:
         - N8N_HOST=localhost
         - N8N_PORT=5678
         - N8N_PROTOCOL=http
         - NODE_ENV=production
         - WEBHOOK_URL=http://localhost:5678/
       volumes:
         - n8n_data:/home/node/.n8n
   volumes:
     n8n_data:
   ```
   - 啟動命令：`docker-compose up -d`
   - 訪問地址：`http://localhost:5678`

3. **熟悉介面**
   - [1] 創建第一個空白工作流程 (Workflow)
   - [2] 拖曳一個「Manual Trigger」節點和「Debug」節點
   - [3] 點擊「Test Workflow」查看輸出

###  工具準備
-  網路工具（確保能訪問 OpenAI, Google, GitHub 等）
-  瀏覽器外掛：**沉浸式翻譯**（中英對照看文檔）
-  註冊帳號：OpenAI / Google AI Studio (Gemini) 獲取 API Key

##  第二階段：動手入門（第2週）

###  目標
- 掌握 5 個核心節點類型
- 完成 3 個基礎自動化流程
- 學會「自學配置第三方服務」的方法

###  核心節點掌握清單

| 節點類型 | 範例節點 | 用途 |
|--------|--------|------|
| **觸發器 (Trigger)** | Schedule, Webhook, App Triggers | 啟動流程的「開關」 |
| **操作類 (Action)** | HTTP Request, Code | 發起請求或運行程式碼 |
| **數據處理** | Edit Fields (Set), If/Switch, Split In Batches | 修改、判斷、拆分數據 |
| **第三方集成** | Google Sheets, Notion, Gmail | 連接外部服務 |
| **調試類** | Debug (Console) | 查看中間結果 |

###  三個實戰小練習

####  練習1：定時發送一句問候
- **目標**：每天上午9點，自動打印「早安！」
- **節點組合**：`Schedule Trigger` → `Code` (生成問候語) → `Debug`
- **關鍵點**：學會設置 Cron 表達式（`0 9 * * *`）

####  練習2：讀取 Google Sheets 數據
- **目標**：從你的 Google 表格中讀取第一行數據
- **步驟**：
  1. 在 Google Cloud Console 創建專案，啟用 Google Sheets API
  2. 在 n8n 中添加 Google Sheets Credentials (OAuth2)
  3. 使用 Google Sheets 節點，選擇「Get Rows」
- **提示**：遇到問題？截圖發給 ChatGPT：「我在 n8n 連接 Google Sheets 時報錯……」

####  練習3：自動保存稍後閱讀到 Notion
- **目標**：模擬一個「收藏即歸檔」流程
- **節點組合**：`Webhook`（模擬接收數據）→ `Notion`（創建 Page）
- **字段映射**：將標題、鏈接、摘要寫入 Notion Database

>  **學習重點**：熟悉 JSON 數據結構，理解 n8n 中數據是如何在節點間流動的。

##  第三階段：接入 AI（第3週）

###  目標
- 讓 AI 參與自動化流程
- 掌握 **AI Agent** 的概念與應用
- 學會讓 AI 調用工具 (Tool Calling)

###  AI 能力接入路徑 (2025 新標準)

#### 方式1：使用 Basic LLM Chain (簡單任務)
- 適用於：摘要生成、翻譯、簡單分類
- 節點：`Basic LLM Chain` + `OpenAI Model` (或 Gemini Model)
- 操作：輸入 Prompt，直接獲取 AI 回覆。

#### 方式2：使用 AI Agent Node (推薦 - 核心能力)
- **這是 n8n 目前最強大的 AI 功能**。
- **特點**：Agent 可以「思考」，它可以根據你的目標，自主決定使用什麼工具。
- **組件**：
    - **Agent**：大腦 (如 OpenAI Tools Agent)
    - **Model**：模型 (GPT-4o, Gemini 1.5 Pro)
    - **Tools**：工具 (Calculator, HTTP Request, 或其他的 n8n Workflow)
    - **Memory**：記憶 (Window Buffer Memory)
- **場景**：告訴 Agent「幫我查詢這家公司的最新新聞並寫成報告發郵件」，Agent 會自動拆解任務：搜尋新聞 → 整理內容 → 發送郵件。

###  實戰練習：AI 智能新聞助理

1. **Trigger**：每天早上定時觸發
2. **AI Agent**：
    - 設定目標：「搜尋關於 'AI Automation' 的最新新聞，總結重點。」
    - 工具：連接一個 `SerpAPI` 或 `n8n Google Search` 工具
3. **Output**：將總結發送到 Telegram 或 Slack。

>  成果：你擁有了一個「會上網的 AI 助手」，而不只是一個聊天機器人。

##  第四階段：實戰專案（第4週）

###  目標
- 解決一個你真實的重複性工作
- 完成一個端到端的自動化流程
- 形成可複用的「知識資產」

###  推薦專案（任選其一）

| 專案 | 所需技能 | 輸出成果 |
|------|----------|----------|
| **每日數據簡報** | Schedule + Database + Markdown + 企業微信/Slack | 每天早上自動推送業務數據報告 |
| **跨平台內容同步** | RSS + Notion + Social Media API | 收藏文章自動同步多平台，並由 AI 生成摘要 |
| **AI 智能客服** | Webhook + AI Agent + Vector Store (RAG) | 用戶提問 → AI 檢索知識庫 → 自動回覆 |
| **個人知識流水線** | Reader API + LLM + Notion | 閱讀 → 摘要 → 打標籤 → 歸檔全自動 |

###  專案開發流程
1. **定義問題**：我每天/每週要重複做什麼？
2. **拆解步驟**：這個任務由哪幾個環節組成？
3. **尋找節點**：每個環節是否有現成節點？
4. **設計 Tool**：如果是 AI 專案，思考 AI 需要什麼工具 (Tool)？
5. **搭建流程**：從左到右連接節點，確保數據流動。
6. **調試優化**：用 Debug 模式看中間值，處理報錯。

##  學習心法（必讀）

1. **不要追求「完全理解」**  
   → 很多配置你可能不懂原理，但只要「work」了就先用著。

2. **善用搜索引擎和 AI**  
   → 報錯訊息 → 截圖 → 丟給 ChatGPT：「這個 n8n 錯誤怎麼解決？」

3. **接受不完美**  
   → 低程式碼的穩定性不如工程系統，但勝在**靈活、快速**。先完成，再完美。
