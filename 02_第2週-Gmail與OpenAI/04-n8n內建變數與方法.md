#  n8n 內建變數與方法（表達式速查）

n8n 雖是類低代碼平台，但在節點間「取數、改數、拼數」的場景下，經常需要在表達式或 Code 節點裡寫少量代碼。本文整理 n8n 常用的內建變數與方法，配以可直接複製的示例，幫你高效完成數據處理。

> 提示：本文示例默認用於「表達式模式」。請將輸入框切換為 Expression，並用 `{{ ... }}` 包裹表達式。

---

## 0. 快速上手：表達式基礎

- 切換到 Expression 後，使用 `{{ 表達式 }}`
- 可直接訪問上游項 `json`/`binary` 數據
- 支持 Javascript 表達式與 n8n 擴展變數/方法混用

示例：
```text
{{ $json.title || $json.name || "未命名" }}
```

---

## 1. 內建變數（Built-ins）

### 1.1 當前節點輸入（Current node input）
- `$input.item`：當前正在處理的輸入項（包含 `json` 與可選 `binary`）
- `$input.all()`：返回所有輸入項數組
- `$input.first()` / `$input.last()`：第一項 / 最後一項
- `$input.params`：上游節點的設置快照（如結果限制、操作類型）
- `$json`：`$input.item.json` 的簡寫
- `$binary`：`$input.item.binary` 的簡寫
- `$input.context.noItemsLeft`：僅在「Loop Over Items」場景下，是否無剩餘項

示例：
```text
{{ $json.name }}
{{ $input.all().map(i => i.json.id) }}
{{ $input.first().json.title }}
```

### 1.2 訪問其他節點的輸出（Output of other nodes）
使用 `$("<node-name>")` 訪問指定節點：
- `$("節點名").all(branchIndex?, runIndex?)`
- `$("節點名").first(branchIndex?, runIndex?)`
- `$("節點名").last(branchIndex?, runIndex?)`
- `$("節點名").item`：與當前項相連的那一條輸出
- `$("節點名").params`：該節點的配置參數快照
- `$("節點名").itemMatching(currentNodeInputIndex)`：在 Code 節點追溯輸入來源

示例：
```text
{{ $("HTTP Request").first().json.title }}
{{ $("Create User").item.json.id }}
```

### 1.3 平台與執行元數據（n8n metadata）
- `$env`：讀取環境變數（如 `.env`）
- `$execution.*`：本次執行上下文（`id`、`mode`、`resumeUrl`、`customData`）
- `$getWorkflowStaticData(type)`：讀寫工作流級靜態數據（`global`/`node`）
- `$("節點名").isExecuted`：該節點是否已執行
- `$itemIndex`：當前項的索引（從 0 開始）
- `$nodeVersion`：當前節點版本
- `$prevNode.*`：上一個節點信息（`name`/`outputIndex`/`runIndex`）
- `$runIndex`：當前節點運行輪次
- `$secrets`：密鑰集合
- `$vars`：可用的變量集合
- `$version`：n8n 版本
- `$workflow.*`：工作流信息（`id`/`name`/`active`）

示例：
```text
{{ $env["API_KEY"] }}
{{ $workflow.id }}
{{ $execution.mode }}
```

### 1.4 日期與時間（Luxon）
- `$now`：當前時間（Luxon DateTime）
- `$today`：今日（去時分秒的 DateTime）

示例（注意 Luxon 格式化）：
```text
{{ $now.toISO() }}
{{ $today.toFormat('yyyy-LL-dd') }}
```

### 1.5 HTTP 節點分頁變數（僅 HTTP 節點）
- `$http.pagination.page` / `perPage` / `total` / `totalPages`

示例：
```text
{{ $http.pagination.page }}
```

### 1.6 LangChain 代碼節點變數（僅 LangChain Code）
- `$llmInput`：模型輸入
- `$generateText()`：生成文本的方法
- `$memory`：記憶對象

示例：
```text
{{ $generateText($llmInput) }}
```

## 2. 常用內建方法（Helpers）

### 2.1 JMESPath 查詢：`$jmespath(expression, data)`
對複雜 JSON 進行搜索/篩選/投影。

示例數據：
```json
{
  "users": [
    { "id": 1, "name": "John", "email": "john@example.com" },
    { "id": 2, "name": "Jane", "email": "jane@example.com" }
  ]
}
```

示例：
```text
{{ $jmespath('users[*].email', $json) }}            // => ["john@example.com","jane@example.com"]
{{ $jmespath('users[?id > `1`]', $json) }}          // => 過濾出 id>1 的用戶
```

### 2.2 便捷方法
- `$evaluateExpression(expression, itemIndex?)`：把字串當表達式求值
- `$ifEmpty(value, defaultValue)`：空值兜底
- `$if(condition, valueIfTrue, valueIfFalse)`：條件分支
- `$max(...numbers)` / `$min(...numbers)`：求最大/最小

示例：
```text
{{ $evaluateExpression('1 + 2') }}                  // 3
{{ $ifEmpty($json.description, 'No description') }}
{{ $if($json.status === 'success', 'OK', 'Error') }}
{{ $max(3, 5, 1) }}  {{ $min(3, 5, 1) }}
```

## 3. 數據轉換與常見 JS 操作（在表達式中使用）

n8n 表達式支持標準 JavaScript 能力，建議優先使用原生方法，避免各版本差異。

- 字串：
```text
{{ ($json.title || '').toLowerCase() }}
{{ ($json.text || '').includes('關鍵字') }}
{{ ($json.slug || '').trim().replace(/\s+/g,'-') }}
```

- 數字：
```text
{{ Number($json.count || 0) }}
{{ (Number($json.price)||0).toFixed(2) }}
```

- 數組：
```text
{{ ($json.items || []).map(i => i.id) }}
{{ ($json.items || [])[0] }}                 // 第一項
{{ ($json.items || []).filter(i => i.ok) }}
{{ Array.from(new Set(($json.tags||[]))) }}  // 唯一化
```

- 對象：
```text
{{ Object.keys($json) }}
{{ JSON.stringify($json.payload || {}) }}
```

- 日期（Luxon）：
```text
{{ $now.plus({ days: 7 }).toISO() }}
{{ $now.setZone('Asia/Shanghai').toFormat('yyyy-LL-dd HH:mm') }}
```

## 4. 使用場景示例

1) 獲取當前節點輸入裡的郵箱：
```text
{{ $json.email }}
```

2) 獲取名為 Webhook 的首條消息：
```text
{{ $("Webhook").first().json.message }}
```

3) 獲取當前工作流名稱與執行 ID：
```text
{{ $workflow.name }} - {{ $execution.id }}
```

4) 生成「今天」與「7 天后」的日期：
```text
{{ $today.toFormat('yyyy-LL-dd') }} / {{ $now.plus({days:7}).toFormat('yyyy-LL-dd') }}
```

5) JMESPath 提取與篩選：
```text
{{ $jmespath('data.items[?active==`true`].name', $json) }}
```

## 5. 速查表（Cheatsheet）

常用變數：
- 當前輸入：`$json`、`$binary`、`$input.item`、`$input.all()`、`$input.first()`、`$input.last()`
- 節點取數：`$("節點名").first().json`、`$("節點名").item.json`
- 平台信息：`$env`、`$workflow.*`、`$execution.*`、`$runIndex`、`$itemIndex`
- 時間：`$now`、`$today`（配合 `toISO()` / `toFormat()`）

常用方法：
- JMESPath：`$jmespath(expr, data)`
- 條件與兜底：`$if()`、`$ifEmpty()`
- 計算：`$evaluateExpression()`、`$max()`、`$min()`

---

## 6. 常見坑位與建議

- 表達式與純文本混用時，注意用 `{{ }}` 包裹表達式；字串內的花括號請轉義
- Luxon 的格式化使用 `toFormat('yyyy-LL-dd')` 等新式 tokens，避免 `YYYY-MM-DD`
- 取其他節點輸出時，確保節點名完全匹配；多分支/多次運行時可用 `first(runIndex)` 精確定位
- 大算子請在 Code 節點完成；表達式中保持「取值與輕度操作」為主
