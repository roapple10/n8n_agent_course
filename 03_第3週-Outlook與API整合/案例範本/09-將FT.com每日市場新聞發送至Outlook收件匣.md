# 將 FT.com 每日市場新聞發送至 Outlook 收件匣

這是一個針對金融市場觀測與新聞自動推送的解決方案。

## 核心目標
每天定時從金融時報（FT.com）抓取最新的市場新聞，並將其格式化後發送到指定使用者的 Outlook 收件匣。

## 工作流來源
[Receive Daily Market News from FT.com to your Microsoft outlook inbox.json](https://github.com/roapple10/awesome-n8n-templates/blob/main/Gmail_and_Email_Automation/%F0%9F%93%88%20Receive%20Daily%20Market%20News%20from%20FT.com%20to%20your%20Microsoft%20outlook%20inbox.json)

## 邏輯說明
1. **定時觸發**：每天固定時間點啟動（例如早上 8:00）。
2. **網頁抓取**：對 FT.com 的市場新聞頁面發起請求。
3. **內容提取**：提取新聞標題、簡述及原文鏈接。
4. **郵件格式化**：將提取的數據組合成 HTML 格式的精美郵件。
5. **發送至 Outlook**：使用 Outlook 節點將這份「市場早報」發送給目標收件人。

## 適用場景
需要隨時掌握金融市場動態的專業投資人、分析師，或是希望自動化獲取每日資訊的讀者。
