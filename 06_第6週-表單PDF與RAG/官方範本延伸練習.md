# 官方範本延伸練習：Basic RAG chat

## 官方範本

- [Basic RAG chat（n8n 範本 5028）](https://n8n.io/workflows/5028-basic-rag-chat)
- 本機 JSON：[官方範本-5028-Basic-RAG-chat.json](案例範本/官方JSON/官方範本-5028-Basic-RAG-chat.json)

這份範本示範兩條路徑：先把文件切成文字片段並寫入 In-Memory Vector Store，再透過聊天觸發器檢索相關片段，交給 Groq Chat Model 回答。範本使用 Cohere Embeddings 產生向量，因此練習時需要 Groq 和 Cohere 兩組 API 憑證。

## 練習順序

1. 先閱讀[《RAG 入門：讓 AI 根據 PDF 文件回答問題》](00-RAG入門與PDF問答實作.md)，理解索引與提問兩階段。
2. 匯入本資料夾的官方 JSON。
3. 依教材設定 Groq 與 Cohere 憑證，以及可由 n8n 執行環境讀取的文字檔或 PDF。
4. 執行 **Test Workflow** 建立向量索引，再開啟 **Chat** 提問。
5. 用 5 個文件有答案的問題和 2 個文件沒有答案的問題測試，記錄引用依據與模型是否猜測。

## 觀察與回答

- 哪個節點把文件拆成片段？
- 哪兩個節點負責將文件和問題轉成向量？為什麼要使用相同的 Embedding 設定？
- Groq Chat Model 在流程中負責哪一個步驟？
- 當問題超出文件內容時，模型是否仍給出答案？你如何改善它？
- In-Memory Vector Store 有什麼限制？

> API 模型和範本可能隨時間更新。若匯入後的 Groq 模型名稱已無法使用，請依教材改選 Groq 帳戶目前提供的模型。
