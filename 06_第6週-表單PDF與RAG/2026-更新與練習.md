# 2026 更新：文件問答與 RAG 練習

進階自動化不只是增加節點，也要理解資料如何流動與如何檢查結果。本週以一份文件問答工作流程認識 RAG：文件會先載入、切塊、轉成 Embedding 並寫入向量儲存區；提問時再檢索相關片段，交由聊天模型根據片段回答。

本週練習使用 n8n 官方 **Basic RAG chat** 範本。Groq Chat Model 負責生成回答；Cohere Embeddings 負責把文件與問題轉成向量。兩者是不同服務，需要各自的 API 憑證。範本使用 In-Memory Vector Store，適合練習與原型，重新啟動後可能需要重新索引。

## 課堂練習

依照[《RAG 入門：讓 AI 根據 PDF 文件回答問題》](00-RAG入門與PDF問答實作.md)完成官方範本匯入、憑證設定、文件索引與聊天測試。準備 5 個文件有答案的問題和 2 個文件沒有答案的問題，檢查回答是否有文件依據，並記錄一個可能造成錯誤的因素。
